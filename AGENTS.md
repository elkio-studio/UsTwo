# Instrucciones de documentación de UsTwo

Consulta el [proceso SDD](docs/proceso-sdd.md) y las [decisiones técnicas](docs/decisiones-tecnicas.md).
Para crear una spec, sigue la [guía local](.agents/skills/ustwo-spec/SKILL.md).
Usa `docs/specs/ep-NN-tema/NNN-slug/spec.md` y asigna el siguiente número
global tras revisar todos los grupos y las specs en curso en desarrollo.
Conserva identificador, nombre y estado al copiar una spec existente.
